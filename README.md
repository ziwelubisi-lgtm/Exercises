# Exercises
📘 Overview

This repository contains a collection of SQL fundamental exercises designed to help learners build a strong foundation in querying relational databases. The exercises progress from basic concepts to more advanced topics, making it suitable for beginners and those looking to refresh their SQL skills.

🎯 Objectives

By completing these exercises, I was able to:

Understand basic SQL syntax
Retrieve data using SELECT statements
Filter data using WHERE clauses
Sort results with ORDER BY
Perform aggregations using functions like COUNT, SUM, AVG, MIN, and MAX
Group data using GROUP BY
Filter grouped data using HAVING
Combine tables using JOIN operations
Use UNION to merge result sets
Apply conditional logic using CASE
